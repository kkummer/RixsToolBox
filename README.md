# RixsToolBox

RixsToolBox is a data analysis software for data collected at the ESRF ID32 and Diamond I21 RIXS end stations. This software is provided "as is". Feature requests and bug reports are very welcome.

## Installation

Make sure you have Python 3 installed on your computer. We recommend using the Anaconda distribution; you can download it from https://www.anaconda.com/products/distribution.

Once the Anaconda distribution is installed, open the `Anaconda Prompt` terminal and type the following command to install the package:

```sh
pip install --ignore-installed  git+https://gitlab.esrf.fr/scientific-software/rixstoolbox.git
```

The `--ignore-installed` argument is required if you want to upgrade an existing installation.

Alternatively, you can download bundled applications for Windows and macOS from [this](https://silx.gitlab-pages.esrf.fr/bob/rixstoolbox) page.
